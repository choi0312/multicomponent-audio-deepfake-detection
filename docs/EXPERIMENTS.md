## 개선되지 않은 조건

평균 개선만 보고 실패 사례를 숨기지 않았다.

- 가짜 반주가 있는 보컬의 Voice EER: `0.075 → 0.150`
- clean 혼합 장면 Voice EER: `0.1167 → 0.1250`
- 보컬 장면 File EER: `0.1327 → 0.1623`
- MP3 Voice/Music, AAC Voice, 채널 변형 Music도 일부 악화

보컬 solo Voice는 혼합 전 0.150에서 최종 shrinkage 후 v2와 같은 0.075로 회복했다. 전체 보컬 Voice는 0.1611에서 0.1361로 개선됐다.

## 이미 관찰한 test/stress 진단

최종 설정을 고정한 뒤, 이전 라운드에서 이미 관찰했던 1,005행을 진단 목적으로만 다시 계산했다. weighted error는 `0.202329 → 0.182489`였지만 보컬 solo 및 가짜 반주 조건은 악화됐다.

이 자료는 새로운 독립 holdout이 아니며 후보 재선정에 사용하지 않았다.

## 수치·실행 검증

- ArtifactNet zero-energy 수정: 원래 정의되던 58 CPU 창과 출력 차이 0
- ArtifactNet CPU/GPU 77창 최대 확률 차이 0.000402391
- Fourier 두 전처리: 고정 upstream 구현과 feature exact match
- 최종 package CPS: smoke 8 + 외부 8 실제 파형에서 같은 GPU v2와 bit-exact
- L40S cache와 actual inference 16파일: 새 expert feature 최대 차이 0
- L40S↔L4 8파일: File 0.002110, Voice 0.000285, Music 0.007534 최대 차이; 세 출력 모두 pairwise rank reversal 0/28
- 최종 ZIP L4 offline 실행과 schema/순서/유한값 검사 통과

## 선택 편향

같은 dev에서 480개 후보와 추가 5개 alpha를 비교했다. generator/domain별 EER도 반복 관찰했다. 따라서 표의 개선 폭은 순수한 일반화 추정치가 아니라 선택 과정이 반영된 값이다. 향후 개선에서는 새로운 generator와 실제 전화 채널로 구성한 사전 등록 holdout이 필요하다.
